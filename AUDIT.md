# Аудит исходных прототипов

Дата аудита: 30 июля 2026 года.

## Какая версия была последней

По времени изменения файлов последняя версия —
`beatport_random_bot subgenre select2.py` (1 февраля 2025 года, 08:20).
Git-метаданных в исходной папке не было, поэтому более надёжной истории версий
восстановить нельзя.

Она запускала Telegram-бота с тремя действиями:

1. найти случайный релиз Beatport;
2. открыть релизы случайного дня;
3. выбрать жанр, затем поджанр и повторить один из вариантов.

Выбор сохранялся в оперативной памяти отдельно для Telegram user ID.

## Критические проблемы

- В четырёх исходниках были открыто сохранены три Telegram-токена. Их следует
  считать скомпрометированными и отозвать через BotFather.
- Beatport отвечает HTML-парсеру `403`, поэтому поиск релиза и проверка страницы
  завершаются неудачей после 15 запросов.
- Синхронный `requests.get()` выполнялся внутри async-обработчика Telegram и
  блокировал обработку всех пользователей.
- У HTTP-запросов не было timeout и обработки сетевых исключений.
- ID поджанров выглядели как заполнители (`123`–`128`), не были связаны с
  жанрами и формировали неподтверждённый URL.

## Существенные дефекты

- Случайная дата начиналась с 1970 года, хотя Beatport появился намного позже:
  подавляющее большинство попыток приходилось на пустые даты.
- После смены жанра старый поджанр пользователя не очищался.
- Состояние хранилось в глобальных словарях, терялось при перезапуске и росло
  без ограничений.
- В репозитории не было зависимостей, инструкции запуска, тестов, логирования,
  обработки ошибок и правил исключения секретов.
- Имена файлов содержали пробелы и слова `test`, хотя это были отдельные версии,
  а не автоматические тесты.
- Текст исходников отображался с повреждённой кодировкой.

## Что исправлено

Публикуемая версия не обходит Cloudflare и не выдаёт случайную страницу за
конкретный релиз. Она создаёт корректную ссылку на каталог Beatport за дату
между 2004 годом и сегодняшним днём, поддерживает постраничный выбор жанра,
сброс выбора, `/help`, логирование и обработчик ошибок. Состояние пользователя
хранится штатно в `context.user_data`.

Секрет читается из `TELEGRAM_BOT_TOKEN`; добавлены `.gitignore`, пример
окружения, фиксированные зависимости, тесты и документация.

## Предлагаемые следующие дополнения

1. После получения официального доступа Beatport API вернуть настоящее
   случайное извлечение релиза через документированный API.
2. Добавить SQLite persistence для выбора жанра и истории ссылок.
3. Добавить Dockerfile и health check для постоянного хостинга.
4. Добавить CI с `pytest` и `ruff`.
5. Получать актуальный список жанров через официальный API вместо статического
   справочника.
