# Beatport Random Bot

Telegram-бот формирует ссылку на каталог треков Beatport за случайный день.
Поддерживаются 46 актуальных категорий Beatport, мультивыбор жанров, поиск
поджанров, диапазон дат и ограничение конкретным годом.

## Почему бот не парсит Beatport

Старые прототипы пытались извлекать ссылки на релизы из HTML. Сейчас Beatport
защищает сайт Cloudflare и отвечает таким скриптам кодом `403`. Официальный API
доступен только одобренным клиентам с API-ключом. Поэтому эта версия формирует
прямую ссылку на страницу каталога и не обходит защиту сайта.

## Запуск

Требуется Python 3.11+ и новый токен Telegram-бота.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:TELEGRAM_BOT_TOKEN="новый-токен-из-BotFather"
python bot.py
```

### Простой запуск в Windows

1. Скопируйте `.env.example` в `.env`.
2. Вставьте токен после `TELEGRAM_BOT_TOKEN=`.
3. Запустите `start_bot.bat` двойным щелчком.

Окно запуска не закроется при ошибке и покажет её причину.
Повторный запуск при уже работающем боте будет остановлен с понятным сообщением,
чтобы Telegram polling не получил ошибку `409 Conflict`.

Все основные действия доступны из меню `/start`:

- случайный релиз — исходная функция рабочего прототипа;
- релизы за один случайный день — исходная функция рабочего прототипа;
- выбор одного или нескольких жанров;
- выбор и поиск поджанра;
- готовые периоды 30, 90 и 365 дней;
- конкретный год;
- произвольный диапазон дат;
- сброс фильтров.

Команды `/year`, `/dates` и `/subgenre` сохранены для опытных пользователей,
но для обычной работы их вводить не требуется. Текстовый ввод нужен только для
произвольного диапазона или поиска поджанра — бот сам попросит его после
нажатия соответствующей кнопки.

Если Beatport блокирует HTML-запрос к списку релизов, кнопка «Случайный релиз»
запускает обычный локальный Chrome в фоне и читает отрендерованную страницу.
Страница случайного дня никогда не подставляется вместо конкретного релиза.
Для кнопки случайного дня бот, как и исходный прототип, сначала убеждается, что
на странице действительно есть релизы.

Каждый результат отправляется новым сообщением и не затирает предыдущий.
Выданные release URL сохраняются в локальной SQLite-базе отдельно для каждого
Telegram user ID и не повторяются после перезапуска бота.

Ссылка также помещается в текст сообщения: Telegram автоматически показывает
карточку страницы с названием и обложкой релиза, когда Beatport разрешает
серверу Telegram получить метаданные страницы.

При выборе нескольких жанров бот случайно выбирает один из отмеченных жанров
для каждой новой ссылки. Beatport не поддерживает объединение нескольких
жанров в одной странице каталога.

## Предпрослушка

На страницах Beatport присутствуют короткие MP3-превью. Наиболее надёжный
способ получать их адреса — официальный Beatport API, который доступен только
одобренным клиентам и требует ключ.

Экспериментальная предпрослушка включена для страниц, HTML которых доступен
боту: парсер читает структурированный `sample_url`, проверяет домен
`geo-samples.beatport.com`, связывает его с release ID и отправляет MP3 через
Telegram. Если Beatport отвечает Cloudflare `403`, бот оставляет ссылку на
каталог и не пытается подставить аудио от другого релиза.

## Безопасность

Токен хранится только в переменной `TELEGRAM_BOT_TOKEN`. Не добавляйте `.env`
или токен в Git. Токены, когда-либо сохранённые в старых файлах, необходимо
отозвать через BotFather, даже если позже они были удалены из кода.
